# Docencia360

Plataforma SaaS mobile-first para docentes y estudiantes.

## Objetivo inicial
Construir primero la base central del producto antes de desarrollar el dashboard:

- Arquitectura frontend responsive y mobile-first.
- Autenticación y perfiles.
- Roles de profesor y estudiante.
- Clases y relación profesor-estudiante.
- Base de datos segura en Supabase con RLS.
- Estructura preparada para tareas, exámenes, asistencia, calificaciones, planificación, materiales y notificaciones.

## Principios

1. El teléfono es el dispositivo principal.
2. Las acciones frecuentes deben requerir pocos pasos.
3. La base de datos se diseña antes de construir pantallas complejas.
4. Seguridad y aislamiento de datos desde el primer día.
5. Componentes reutilizables y arquitectura preparada para crecer.
